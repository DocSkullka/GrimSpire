# GrimSpire: Ascent of the Cursed 🏰💀

> **Мрачный пошагово-симулируемый автобатлер-рогалик (Roguelite Tower Climber)** в стиле *Don't Starve* и *Darkest Dungeon*.

---

## ⚔️ О проекте (Concept Overview)

Персонаж попадает в древнюю Проклятую Башню. Каждый этаж представляет собой арену, на которой происходит автоматическое сражение с противниками или боссами.

### Ключевые столпы геймплея:
1. **Автоматический бой (Auto-Combat)**: Сражения происходят без прямого кликанья по врагам. Игрок управляет билдостроением, экипировкой, синергиями и прокачкой.
2. **Первый этаж (Вводный)**: Первый этаж гарантированно проходимый (одиночный слабый противник/манекен), чтобы игрок сразу получил первую награду.
3. **Драфт 3 предметов после каждого этажа**: За зачистку этажа случайно генерируются 3 предмета экипировки (Оружие, Броня, Шлем, Оффхенд, Аксессуар). Игрок выбирает один из них.
4. **Смерть и Мета-прогрессия (Roguelite Loop)**:
   - При гибели на любом этаже вся экипировка, собранная во время забега, сгорает.
   - Персонаж возвращается на 1 этаж (в Лагерь у подножия башни).
   - **Золото остаётся навсегда**!
   - В Лагере за золото у Кровавого Алтаря игрок перманентно прокачивает базовые характеристики: Здоровье, Урон, Броню, Скорость атаки, Крит, Вампиризм и Множитель золота.
5. **Боссы каждые 10 этажей**:
   - Этаж 10: *Gargoyle Overseer Malgorath*
   - Этаж 20: *The Flesh Amalgam of Sorrow*
   - Этаж 30: *Valthor the Soul Extinguisher*
   - Уникальные механики, огромный пул здоровья и повышенные награды.

## 🎨 Визуальный стиль (Art & Aesthetic)

- **Направление**: Тёмная готика, мрачный гротеск в духе *Don't Starve* и *Darkest Dungeon*.
- **Графика**: 2D графика с толстыми штрихованными контурами, текстурой бумаги/чернил, приглушённой палитрой (пепельный, кровь, болотный, тусклое золото факелов).
- **Слоевая бумажная кукла (Modular Paper-Doll)**: Экипированные предметы отображаются прямо на спрайте персонажа (меч, шлем, броня, щит).
- **Освещение и шейдеры**: 2D Canvas Lighting (динамические тени от факелов, виньетка безумия, частицы пепла и крови).

## 🛠️ Стек технологий и Архитектура

### Выбранный движок:
- **Godot Engine 4.3+ (C# .NET 8 / GDScript)**
  - *Почему Godot*: 100% бесплатный (MIT), легковесный (~100 МБ), текстовые форматы сцен (`.tscn`), нативная поддержка C# .NET 8, превосходный 2D рендерер со встроенными 2D Normal Maps, CanvasItem шейдерами и системой частиц.
- **Архитектура чистого ядра (Clean Engine-Agnostic Core)**:
  - Вся боевая логика, формулы урона, генератор этажей и мета-прогрессия вынесены в `GrimSpire.Core` на C# .NET 8.
  - Движок (Godot) выступает лишь слоем отображения (Presentation Layer).
  - Это позволяет моментально прогонять сотни симуляций для балансировки без запуска GUI.

## 🚀 Запуск и тестирование ядра прямо сейчас

В репозитории уже реализована и протестирована полная математическая модель игры:

1. **Запуск тестов**:
   ```bash
   dotnet test
   ```
2. **Запуск симулятора баланса (50 авто-забегов с графиком этажей)**:
   ```bash
   dotnet run --project src/GrimSpire.Cli -- --simulate
   ```
3. **Интерактивная игра через консоль**:
   ```bash
   dotnet run --project src/GrimSpire.Cli
   ```
