# Game Design Document: GrimSpire (Башня Бесконечного Падения)

## 1. Введение и Концепция
- **Рабочее название**: GrimSpire: Ascent of the Cursed
- **Жанр**: Roguelite Auto-Battler / Tower Climber
- **Целевая аудитория**: Любители *Loop Hero*, *Vampire Survivors*, *Darkest Dungeon*, *Don't Starve*, *Brotato*, *Backpack Hero*.
- **Платформа**: PC (Windows / Linux / Steam / Web)

### Главный игровой крючок (Core Hook):
Вы не тратите реакцию на клики по врагам — исход сражения решается вашим тактическим чутьем: выбором снаряжения после каждого этажа, комбинацией синергий и вложением несгораемого золота в постоянные атрибуты после каждой неминуемой смерти.

## 2. Геймплейный цикл (Core Gameplay Loop)

```text
       ┌───────────────────────────────┐
       │   Базовый Лагерь (Hub)        │
       │   - Трата золота на Алтаре    │
       │   - Выбор начального билда    │
       └──────────────┬────────────────┘
                      │ Вход в Башню
                      ▼
       ┌───────────────────────────────┐
       │   Этаж N (Сражение)           │◄────────┐
       │   - Автоматический бой        │         │
       │   - Сбор золота за мобов      │         │
       └──────────────┬────────────────┘         │
                      │ Победа                   │
                      ▼                          │
       ┌───────────────────────────────┐         │ Следующий этаж
       │   Драфт Награды               │         │ (сложнее на 12%)
       │   - Выбор 1 из 3 предметов   │─────────┘
       │   - Экипировка в слот         │
       └──────────────┬────────────────┘
                      │ Поражение (HP <= 0)
                      ▼
       ┌───────────────────────────────┐
       │   Смерть Персонажа            │
       │   - Вся экипировка сгорает    │
       │   - Золото сохраняется        │
       │   - Возврат на Этаж 1         │
       └───────────────────────────────┘
```

## 3. Боевая механика (Auto-Combat Math)

### Формула снижения урона броней:
$$\text{DamageMultiplier} = \frac{100}{100 + \text{Armor}}$$
- При 0 брони: входящий урон 100%
- При 25 брони: входящий урон 80% (20% снижения)
- При 50 брони: входящий урон 66.7% (33.3% снижения)
- При 100 брони: входящий урон 50% (50% снижения)

### Критический урон:
$$\text{Damage} = \text{AttackDamage} \times \text{CritMultiplier}$$
- Базовый шанс крита: 5%
- Базовый множитель: 1.5x (150%)

### Вампиризм (Lifesteal):
$$\text{HealAmount} = \text{DealtDamage} \times \text{LifestealPercent}$$

### Скорость атаки:
Интервал между ударами:
$$\text{IntervalSeconds} = \frac{1.0}{\text{AttackSpeed}}$$

## 4. Система экипировки и Драфта (Item Drafting)

### 5 Слотов:
1. **Weapon (Оружие)**: Мечи, секиры, кинжалы, косы. Дают урон, скорость атаки, крит.
2. **Armor (Броня)**: Латы, кожа, костяные панцири. Дают здоровье и броню.
3. **Helmet (Шлем)**: Защита головы, шанс уклонения, защита от оглушения.
4. **Off-Hand (Оффхенд)**: Щиты, гримуары, фонари душ. Броня, парирование, вампиризм.
5. **Accessory (Амулет/Кольцо)**: Тринкеты со спецэффектами и множителями.

### 6 Градаций редкости:
- ⚪ **Common**: Базовые характеристики.
- 🟢 **Uncommon**: +1 дополнительный аффикс.
- 🔵 **Rare**: +2 аффикса, повышенные числовые значения.
- 🟣 **Epic**: Высокие статы + пассивное боевое свойство (например: "Каждый 3-й удар оглушает на 1с").
- 🟠 **Legendary**: Изменяющие правила билдообразующие свойства (например: "При HP < 30% скорость атаки удваивается").
- 🔴 **Cursed (Проклятые)**: Сверхмощный положительный эффект, сопровождающийся негативным штрафом (например: +100% урона, но -20 брони).

---

## 5. Прогрессия Башни и Боссы

- **Этаж 1**: Всегда простой бой (Скелет/Манекен), обучающий механике выбора предметов.
- **Этажи 2–9, 11–19, 21–29...**:
  - Случайное появление 1–3 врагов.
  - Шанс появления Элитных врагов (с 4 этажа) с аурами (Vampiric, Berserk, Shielded).
- **Каждые 10 этажей — БОСС**:
  - **Этаж 10**: *Gargoyle Overseer Malgorath* (каменный страж, огромная броня, слэм-атаки).
  - **Этаж 20**: *The Flesh Amalgam of Sorrow* (ядовитые плевки, призыв миньонов).
  - **Этаж 30**: *Valthor the Soul Extinguisher* (высасывание жизни, неуязвимость в призрачной фазе).

---

## 6. Мета-прогрессия (Постоянное золото)

Золото не сгорает при смерти. В лагере доступен **Кровавый Алтарь**:
1. **Titanic Vigor**: +12 Max HP за уровень прокачки.
2. **Brutal Edge**: +2.5 DMG за уровень.
3. **Iron Hide**: +2.0 Armor за уровень.
4. **Frenzied Reflexes**: +0.05 к скорости атаки за уровень.
5. **Anatomy of Slaughter**: +1% к шансу крита за уровень.
6. **Vampiric Hunger**: +1% к вампиризму за уровень.
7. **Greed of the Fallen**: +8% к количеству находимого золота.
